## ৪৯.১ সাইবার নিরাপত্তার তিনটি স্তম্ভ (Three Pillars)

> ⏰ ভিডিও টাইম: (1:49 - 3:54)

সাইবার নিরাপত্তার জগতে সফল হতে গেলে তিনটি মৌলিক বিষয় আয়ত্ত করতে হবে। এগুলোকে বলা হয় **থ্রি পিলারস অফ সাইবারসিকিউরিটি**:

### ১ম স্তম্ভ: নেটওয়ার্কিং (Networking)

নেটওয়ার্কিং হলো সাইবার নিরাপত্তার **মেরুদণ্ড**। তুমি যদি না জানো ডাটা কীভাবে এক জায়গা থেকে আরেক জায়গায় যায়, তাহলে তুমি কখনোই হ্যাকিং বা ডিফেন্স বুঝতে পারবে না।

**কী কী শিখতে হবে:**

| টপিক | বর্ণনা | কেন দরকার? |
|-------|--------|------------|
| TCP/IP | ডাটা প্যাকেট কিভাবে ভ্রমণ করে | সব কমিউনিকেশন বোঝার জন্য |
| OSI মডেল | ৭ লেয়ারের নেটওয়ার্ক মডেল | প্রবলেম সলভিং এর জন্য |
| DNS | ডোমেইন নাম কিভাবে IP তে রূপান্তর হয় | ওয়েব হ্যাকিং বোঝার জন্য |
| HTTP/HTTPS | ওয়েব কমিউনিকেশন প্রোটোকল | ওয়েব অ্যাটাক বোঝার জন্য |
| পোর্ট ও সার্ভিস | কোন পোর্টে কোন সার্ভিস চলে | রিকনেসান্সের জন্য |
| সাবনেটিং | IP রেঞ্জ ও নেটওয়ার্ক ডিভিশন | নেটওয়ার্ক ম্যাপিং এর জন্য |

**কিভাবে শিখবে:**
- Professor Messer-এর Network+ প্লেলিস্ট (YouTube, ফ্রি)
- Cisco Packet Tracer দিয়ে প্র্যাকটিস
- Wireshark দিয়ে প্যাকেট ক্যাপচার করে দেখা
- TryHackMe-এর Networking রুম

### ২য় স্তম্ভ: অপারেটিং সিস্টেম (Operating Systems)

লিনাক্স (Linux) হলো **হ্যাকারের সেরা বন্ধু**। বেশিরভাগ সিকিউরিটি টুলস লিনাক্সে চলে, বিশেষ করে কালি লিনাক্স (Kali Linux)।

**কেন লিনাক্স?**
- ৯০%+ সিকিউরিটি টুলস লিনাক্সে বানানো
- কমান্ড লাইন কন্ট্রোল — GUI ছাড়াই সব করা যায়
- ওপেন সোর্স — সম্পূর্ণ ফ্রি
- সার্ভার ইন্ডাস্ট্রিতে লিনাক্সের রাজত্ব

**লিনাক্সে কী শিখতে হবে:**

```
📂 ফাইল সিস্টেম: ls, cd, pwd, mkdir, rm, cp, mv, find
🔐 পারমিশন: chmod, chown, umask, ACL
📝 টেক্সট: cat, grep, sed, awk, head, tail, cut
🌐 নেটওয়ার্ক: ip, ifconfig, ping, netstat, ss, tcpdump
⚙️ প্রসেস: ps, top, htop, kill, systemctl, journalctl
🔧 প্যাকেজ: apt, dpkg, snap, flatpak
🛡️ সিকিউরিটি: nmap, netcat, tcpdump, iptables
```

**উইন্ডোজও গুরুত্বপূর্ণ:**
- এন্টারপ্রাইজ পরিবেশে ৮০%+ উইন্ডোজ চলে
- Active Directory, PowerShell, Group Policy
- Windows Event Log এনালাইসিস

### ৩য় স্তম্ভ: প্রোগ্রামিং/স্ক্রিপ্টিং (Programming & Scripting)

তোমাকে পেশাদার ডেভেলপার হতে হবে না, কিন্তু **বেসিক স্ক্রিপ্টিং** জানতেই হবে। অটোমেশন আর টুলস বোঝার জন্য এটি অপরিহার্য।

**কোথা থেকে শুরু করবে:**

```bash
# ১. Bash Scripting (সবচেয়ে সহজ)
#!/bin/bash
echo "হ্যালো, সাইবার ওয়ার্ল্ড!"

# ফাইল ব্যাকআপ স্ক্রিপ্ট
#!/bin/bash
tar -czf backup_$(date +%Y%m%d).tar.gz /important/files

# নেটওয়ার্ক স্ক্যানার
#!/bin/bash
for ip in $(seq 1 254); do
    ping -c 1 192.168.1.$ip | grep "bytes from" | cut -d" " -f4
done
```

| ভাষা | কেন শিখবে | কোথায় লাগে |
|-------|------------|-------------|
| **Bash** | লিনাক্স অটোমেশন | টুলস, রিপোর্টিং, রিকন |
| **PowerShell** | উইন্ডোজ অটোমেশন | Blue Team, DFIR |
| **Python** | সবচেয়ে শক্তিশালী | এক্সপ্লয়েট, টুল ডেভেলপমেন্ট |
| **JavaScript** | ওয়েব বোঝার জন্য | ওয়েব সিকিউরিটি, XSS |

### ল্যাব নেটওয়ার্ক ডায়াগ্রাম

```
তোমার হোস্ট মেশিন (ল্যাপটপ)
       │

       └── ইন্টারনেট (TryHackMe, HTB)
```

### গুরুত্বপূর্ণ টিপস

> **নেটওয়ার্ক মোড:** VirtualBox-এ NAT Network ব্যবহার করো। এতে তোমার VM গুলো নিজেদের মধ্যে কথা বলতে পারবে, কিন্তু তোমার রিয়েল নেটওয়ার্ক থেকে আলাদা থাকবে।

> **স্ন্যাপশট:** প্রতিটি VM কনফিগার করার পর snapshot নিয়ে রাখো। কিছু ভুল হলেও রিকভার করতে পারবে।

> **রিসোর্স ম্যানেজমেন্ট:** সব VM একসাথে চালানোর দরকার নেই। দরকার অনুযায়ী চালাও।

## ৪৯.৩ ক্যারিয়ার পাথ: কোন দিকে যাবে? (Career Paths)

> ⏰ ভিডিও টাইম: (6:15 - 8:30)

সাইবার নিরাপত্তায় অনেকগুলো ক্যারিয়ার অপশন আছে। তুমি তোমার আগ্রহ অনুযায়ী যেকোনো একটি বেছে নিতে পারো:

### ব্লু টিম (Blue Team) — ডিফেন্স

ব্লু টিম মানে **প্রতিরক্ষা বাহিনী**। তুমি আক্রমণ ঠেকাবে, সিস্টেম মনিটর করবে, আর নিরাপত্তা বজায় রাখবে।

```bash
echo "   বেতন: এন্ট্রি $50k-$70k / সিনিয়র $90k-$120k"

echo "২. আর্কিটেক্ট"
echo "   কাজ: সিকিউরিটি সিস্টেম ডিজাইন"

echo "৩. কমপ্লায়েন্স অফিসার"

echo "   বেতন: $70k-$100k"
```

রেড টিম মানে **আক্রমণকারী দল**। তুমি কোম্পানির সিস্টেমে দুর্বলতা খুঁজে বের করবে।

### ক্লাউড সিকিউরিটি (Cloud Security)

ক্লাউড এখন সবচেয়ে বড় মার্কেট। AWS, Azure, Google Cloud — এগুলো শিখলে ক্যারিয়ার দ্রুত এগিয়ে যাবে।

| ক্লাউড প্ল্যাটফর্ম | সার্টিফিকেশন | গড় বেতন |
|---------------------|---------------|----------|
| AWS | AWS Certified Security - Specialty | $120k-$160k |
| Azure | Microsoft Azure Security Engineer | $110k-$150k |
| Google Cloud | Professional Cloud Security Engineer | $115k-$155k |

### ডিজিটাল ফোরেনসিক্স ও ইনসিডেন্ট রেসপন্স (DFIR)

DFIR মানে **ডিজিটাল প্রমাণ সংগ্রহ আর আক্রমণ মোকাবেলা**।

**কী কী শিখতে হবে:**
- ফোরেনসিক ইমেজিং (FTK Imager, dd)
- মেমোরি ফোরেনসিক্স (Volatility)
- ডিস্ক ফোরেনসিক্স (Autopsy, Sleuth Kit)
- নেটওয়ার্ক ফোরেনসিক্স (Wireshark, Zeek)
- ম্যালওয়্যার এনালাইসিস (String, PE Studio)

**বেতন:** $80k-$140k

### GRC (Governance, Risk, and Compliance)

GRC হলো নিয়ম-কানুন আর নীতি তৈরি করার কাজ। যারা **লিখতে** ভালোবাসে তাদের জন্য পারফেক্ট।

| টপিক | বর্ণনা |
|-------|--------|
| গভর্নেন্স | নিরাপত্তা নীতি ও প্রসেস তৈরি |
| রিস্ক ম্যানেজমেন্ট | ঝুঁকি চিহ্নিত ও মূল্যায়ন |
| কমপ্লায়েন্স | আইন-কানুন মেনে চলা (GDPR, HIPAA, PCI DSS, ISO 27001) |

**বেতন:** $70k-$130k (সিনিয়র লেভেলে অনেক বেশি)
