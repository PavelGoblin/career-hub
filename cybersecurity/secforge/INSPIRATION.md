# Inspiration

This project was inspired by **Z4nzu/hackingtool** — an excellent all-in-one hacking tool
aggregator for penetration testers and cybersecurity enthusiasts.

While **SecForge** shares the same high-level concept (gathering popular security tools
under one catalog), the codebase is entirely **original**, written from scratch with a
different architectural approach:

| Aspect | Z4nzu/hackingtool | SecForge |
|--------|-------------------|----------|
| CLI approach | Rich TUI menus | argparse commands |
| Tool definitions | Python classes | JSON catalog |
| Installer | Inline shell | Modular installer |
| Config | Python constants | Config files |
| Extensibility | Subclass-based | Catalog-based |

Original project: [https://github.com/Z4nzu/hackingtool](https://github.com/Z4nzu/hackingtool)

Massive thanks to **Z4nzu** and all contributors of `hackingtool` for the inspiration.
