
# অবদান রাখার নির্দেশিকা

আপনার অবদান স্বাগত!

## কিভাবে অবদান রাখবেন

1. **ইস্যু খুলুন** - বাগ রিপোর্ট বা ফিচার রিকোয়েস্ট
2. **Pull Request** - কোড কন্ট্রিবিউট করুন

## PR প্রক্রিয়া

1. রিপোজিটরি ফর্ক করুন
2. নতুন ব্রাঞ্চ তৈরি করুন
```bash
git checkout -b feature/আমার-ফিচার
```
3. পরিবর্তন করুন
4. কমিট করুন
```bash
git commit -m 'বাংলা অনুবাদ যোগ করা হয়েছে'
```
5. পুশ করুন
```bash
git push origin feature/আমার-ফিচার
```
6. Pull Request খুলুন

## গাইডলাইনস

- কোড স্টাইল অনুসরণ করুন
- টেস্ট লিখুন
- ডকুমেন্টেশন আপডেট করুন
- ছোট, ফোকাসড PR রাখুন

ধন্যবাদ! 🎉
