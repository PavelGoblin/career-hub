# 🔧 ট্রাবলশুটিং গাইড

## সাধারণ সমস্যা ও সমাধান

### ১. পাইথন/লাইব্রেরি ইনস্টলেশন সমস্যা

**সমস্যা:** `pip install` কাজ করছে না

**সমাধান:**
```bash
# pip আপডেট করুন
python -m pip install --upgrade pip

# নির্দিষ্ট ভার্সন ইনস্টল
pip install scikit-learn==1.0.2

# virtual environment ব্যবহার
python -m venv ml_env
.\ml_env\Scripts\activate  # Windows
pip install -r requirements.txt
```

### ২. Jupyter Notebook সমস্যা

**সমস্যা:** Jupyter নোটবুক খুলছে না

**সমাধান:**
```bash
# Jupyter ইনস্টল
pip install jupyter notebook

# টোকেন রিসেট
jupyter notebook --generate-config
```

### ৩. মেমোরি/পারফরম্যান্স সমস্যা

**সমস্যা:** বড় ডেটাসেট নিয়ে কাজ করতে পারছেন না

**সমাধান:**
- `df.sample(10000)` দিয়ে ছোট নমুনা নিন
- Data types অপ্টিমাইজ করুন (`df.info()` দেখে)
- Chunking ব্যবহার করুন

### ৪. মডেল ট্রেনিং সমস্যা

| সমস্যা | সম্ভাব্য কারণ | সমাধান |
|--------|---------------|---------|
| ন্যান ভ্যালু | ডেটা ক্লিনিং হয়নি | `df.dropna()` বা `df.fillna()` |
| ওভারফিটিং | ট্রেনিং ডেটা বেশি, মডেল জটিল | Regularization, prune, more data |
| Underfitting | মডেল খুব সহজ | জটিল মডেল, ফিচার বাড়ান |
| Gradient 문제 | স্কেলিং হয়নি | StandardScaler প্রয়োগ |

### ৫. প্লটিং সমস্যা

```python
# যদি প্লট বাংলায় না দেখায়
plt.rcParams['font.sans-serif'] = ['Arial']

# প্লট সাইজ পরিবর্তন
plt.figure(figsize=(12, 8))

# ইন্টারঅ্যাকটিভ মোড

```
